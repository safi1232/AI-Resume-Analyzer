# ResumeIQ – AI Resume Analyzer

An AI-powered resume analysis platform that helps job seekers evaluate their resumes against job descriptions, identify skill gaps, and improve their chances of passing Applicant Tracking Systems (ATS).

🚀 **Live Demo:** [ResumeIQ – AI Resume Analyzer](https://ai-resume-analyzer-28c86tn3a-acme-4a68.vercel.app/)

---

## ✨ Features

- **AI-Powered Resume Analysis:** Analyze resumes and extract relevant information.
- **ATS Compatibility Scoring:** Evaluate how well a resume matches a job description.
- **Job Description Matching:** Compare resume content against specific job requirements.
- **Skill Gap Analysis:** Identify missing and matching skills.
- **Experience Evaluation:** Assess relevant work experience.
- **Education Analysis:** Evaluate educational qualifications against job requirements.
- **PDF Resume Upload:** Upload resumes in PDF format for analysis.
- **Interactive Dashboard:** View analysis results through an intuitive dashboard.
- **Visual Analytics:** Understand performance through interactive charts and score indicators.

ResumeIQ provides an interactive dashboard where users can upload their resumes, enter job descriptions, and receive detailed analysis.

**Key insights include:**
- Overall resume match score
- Skill match percentage
- Experience match score
- Education score
- Required and missing skills
- Resume improvement opportunities

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the Project

```bash
cd ai-resume-analyzer
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the frontend root directory:

```env
VITE_API_URL=https://ai-resume-analyzer-e130ba4c.fastapicloud.dev
```

### 5. Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
